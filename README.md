# Financial-Data-Science
Group Project: Unsupervised Learning - Credit Card Default Prediction & Risk Monitor Model

Homework1: Enhancing Financial Data for Predictive Modeling
1. Use the yfinance library to download historical data (e.g., daily prices including
Open, High, Low, Close, Volume) for diverse financial instruments
(stocks, ETFs, or indices) for the past five years.
2. Handle missing values (e.g., due to market holidays or incomplete records)
3. Plot time series of daily returns
4. Plot moving averages of returns and volatility based on a given window size
5. Extract potential insights and suggest trading actions

Homework2: Predicting stock index returns
1. Choose S&P 500 index (SPY)
2. Predict its next-month monthly return for a period of 5 years (out of sample), using a
   rolling estimation window of past 5 years (in sample)
3. Evaluate prediction performance
4. Use different factor models (Fama-French 3 factors, 5 factors)
5. Use different linear models (LR, ridge, lasso)
